# 角色 / IP 形象设计 — character

**何时用**：真人以外的角色 —— 卡通形象、IP 角色、吉祥物、游戏角色、3D 形象、
魔法师/教师/企业人物等具象人设、儿童绘本角色。

## 填充清单

| 字段 | 必答 |
|---|---|
| 角色类型与用途 | 什么角色，用于游戏/IP/品牌/教育/广告 |
| 身份 | 年龄感、性别/物种、身份职业 |
| 外观 | 脸型、发型、发色、眼睛、表情、身材比例、皮肤/毛毛发质感 |
| 服装 | 上装、下装、鞋、配饰、**标志性元素**（必须保留的识别物） |
| 动作 | 姿态、双手动作、头部与视线朝向 |
| 情绪 | 明显、易读、有亲和力 |
| 造型语言 | 可爱/高级/神秘/未来/专业；轮廓清晰有剪影识别度 |
| 画面 | 全身、头手脚完整、居中、正面或 3/4 侧、纯色或简单背景 |
| 视觉风格 | 3D cartoon / 2D illustration / anime / Pixar-like 3D，材质造型颜色三统一 |
| 光线 | 柔和 studio lighting，均匀，轻轮廓光 |
| 禁止 | 多余人物/手臂/手指、畸形手脚、裁切身体、复杂背景、文字水印 |

IP 角色额外锁：帽子/颜色/徽章/发型/特殊道具等识别元素必须在**任何视角和动作**中
保持一致（跨图时配合 [series.md](series.md) 的 MASTER 块）。

## Z-Image 骨架

```text
title: [角色名/一句话人设], A [风格媒介] character design of [角色类型] for [用途].,
[4-6 个气质词: friendly, playful, professional …],
[简单背景说明: clean solid pastel studio background],
[主体身份组: cartoon character, female, child-like proportions, round silhouette …],
[脸型五官组: round face, large expressive eyes, small smiling mouth …],
[发型发色组: short fluffy mint-green hair, rounded bangs …],
[服装组: mustard yellow jumpsuit, white sneakers, small satchel badge …],
[标志性元素组: signature oversized goggles with star detail, always present …],
[动作组: standing, waving with right hand, looking directly at viewer …],
[情绪组: cheerful, curious, welcoming],
full body, head hands and feet fully visible, centered, front three-quarter view,
3d cartoon style, consistent materials, unified color palette,
soft studio lighting, even illumination, subtle rim light for separation,
high detail, clean silhouette, professional character design, consistent proportions,
single character only, no extra limbs or fingers, no deformed hands, no cropped body,
no complex background, no text, no watermark
```

## 填写要点

- 全身 + 完整头手脚 + 居中是设计稿的硬要求，写进构图组而不是指望默认。
- 「剪影识别度」的落点：一个独特轮廓特征（大帽子、圆身体、长耳朵）+ 一个标志物。
- 风格选**一种**锚定（3D cartoon 就不要混 flat vector），材质/造型/颜色三统一。
- 负面约束照抄骨架末四行，能挡掉绝大多数畸形。

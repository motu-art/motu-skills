# 产品摄影 — product

**何时用**：SaaS/科技产品宣传、工业产品、消费电子、包装设计、汽配以外的通用
商业产品 shot。电商白底主图用 [ecommerce.md](ecommerce.md)，汽车/机械零部件用
[automotive.md](automotive.md)。

## 填充清单

| 字段 | 必答 |
|---|---|
| 产品 | 名称 + 它是什么 |
| 结构 | 主体构成；**必须准确保留**：部件、按钮、接口、Logo 位置、特殊形状 |
| 状态 | 静止/使用中/悬浮/展开 |
| 摆放 | 台面/纯色/环境；主体占画面约 60% |
| 视角 | 正面/45°/侧面/俯视；产品完整可见 |
| 背景 | 纯白/浅灰/深色/品牌色；极简无杂物 |
| 光线 | 柔光箱 + 可控影棚光；柔和反射、干净高光、真实阴影 |
| 材质 | 金属/玻璃/塑料/皮革/木材；真实反射与纹理 |
| 构图 | 视觉中心；给文案留哪一侧空白 |
| 禁止 | 变形、错误结构、多余零件、漂浮阴影、错误 Logo、乱码、额外产品、杂乱背景 |

## 填写要点

- **结构清单是产品模板的灵魂**：把 logo、接口、按键、特殊形状逐个写进结构组 ——
  写了才保得住，没写模型就自由发挥。
- 光圈收到 f/5.6–f/11（产品全清晰），与人像的 f/2.0 相反。
- 给电商/广告叠字留位：`generous negative space on the [left] for copy`。
- 深色产品配 `dark studio with controlled highlights`，浅色产品配浅色无缝背景。

# 社交媒体配图 — social

**何时用**：Instagram / 小红书 / Facebook / LinkedIn / 公众号封面 / X(Twitter)
帖图 —— 有明确平台画幅、核心信息一眼懂的传播图。

## 填充清单

| 字段 | 必答 |
|---|---|
| 平台 | 哪个平台（决定画幅） |
| 内容主题 | 发什么 |
| 核心信息 | 用户看图 1 秒内应理解的一句话 |
| 主体 | 视觉焦点 |
| 构图 | 主体位置；焦点明确 |
| 文字 | 主标题/副标题 —— 逐字引号（社媒图允许少量文字） |
| 风格 | 年轻/专业/高级/生活方式 |
| 视觉层级 | 主体 → 标题 → 辅助信息 → 品牌 Logo |
| 禁止 | 乱码、错拼、额外文字、元素拥挤 |

## 画幅速查

| 平台场景 | preset | 画布 |
|---|---|---|
| 小红书竖图 / Instagram Portrait / Story | `story` 或 `portrait` | 672×1008 / 768×1024 |
| Instagram 方图 / 公众号次图 | `square` | 1024×1024 |
| 公众号头图 / X / LinkedIn 横图 | `landscape` / `banner` | 1024×768 / 1024×576 |

## Z-Image 骨架

```text
title: [帖子主题], A social media visual for [平台] about [主题].,
[4-6 氛围词: vibrant, shareable, modern …],
[背景: 具体背景],
[配色: 主色, 辅色, 强调色 —— 平台调性],
[核心主体组: 具体描述],
[spatial: subject occupying [位置/占比], clear single focal point],
[文字组: bold headline text "[逐字]" in [字体气质] at top, smaller subline text "[逐字]" below, small brand logo at corner],
[层级组: hierarchy from subject to headline to supporting detail],
full_frame, [35/50]mm, f/[4-8], ISO 100, shutter speed: 1/125,
[画幅: vertical social format (4:5) / square], centered focus,
[景深],
[主光 + position: + intensity:],
[辅光 + ratio:],
[光感词],
social media campaign visual, commercial photography, professional art direction,
[调色: 高饱和/低饱和 按平台, contrast:, saturation:],
[调子词],
[叙事句],
[情绪词],
strong visual hierarchy, exact spelling as quoted, no extra text,
no garbled characters, no cluttered composition, no watermark
```

## 填写要点

- 核心信息先浓缩成一句，再决定画面 —— 图是给刷手机的人 1 秒钟看的。
- 文字极简：一个大标题（3–5 词）+ 一行小字，其余交给文案区。
- 平台调性映射配色：小红书/IG = 明快高饱和；LinkedIn/B 端 = 克制专业低饱和。

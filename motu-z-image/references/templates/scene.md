# 场景 / 环境概念图 — scene

**何时用**：游戏场景、电影场景、世界观设定、科幻/奇幻、城市、自然景观、氛围空镜。
无人或人只作为比例参照。室内空间设计用 [architecture.md](architecture.md)。

## 填充清单

| 字段 | 必答 |
|---|---|
| 场景类型 | 一个什么场景 |
| 时间 | 清晨/正午/黄昏/夜晚 |
| 地点 | 具体地点 |
| 环境三层 | 前景 / 中景 / 背景各是什么元素 |
| 空间 | 规模（狭小/开阔/宏大）；纵深明显、层次明确 |
| 建筑/结构 | 风格 + 主要结构 2–3 个 |
| 天气 | 晴/雨/雾/雪；空气中的介质（雾气/尘埃/雨滴） |
| 光线 | 主光源 + 方向 + 阴影性质（长/柔/体积光） |
| 色彩 | 主色/辅色/强调色 |
| 氛围 | 宁静/神秘/宏大/温暖/危险/未来感 |
| 相机 | 广角电影构图、24mm、深透视 |
| 画质 | high-detail environment concept art、atmospheric perspective |

## Z-Image 骨架

```text
title: [场景名], An environment concept art of [场景] at [时间].,
[4-6 氛围词: vast, mysterious, serene …],
[地点: 具体地点],
[前景: 具体元素], [中景: 具体元素], [背景: 具体元素],
[时间天气: dawn, thin mist drifting],
[空气介质: volumetric haze, floating dust motes],
[配色: 主色, 辅色, 强调色],
environment, [空间规模: vast open scale], strong visual depth with distinct foreground midground background layers,
[建筑/结构组: [风格] architecture, [结构1], [结构2], [结构3]],
[spatial: clear recession of scale from foreground to horizon],
full_frame, 24mm, wide-angle, f/8.0, ISO 100, shutter speed: 1/60,
wide establishing shot, horizontal, low angle, horizon on lower third,
deep, sharp throughout with atmospheric haze in distance,
[主光: 太阳/月亮/霓虹 + 性质 + position: + 产生效果: volumetric light shafts / long shadows],
[辅光: bounce / ambient + ratio:],
[光感词],
cinematic environment concept art, realistic materials,
[调色: 冷暖倾向, contrast:, saturation:, 主色调],
[调子词],
[叙事句],
[情绪词],
high-detail environment, rich environmental storytelling, atmospheric perspective,
no figures in foreground, no text, no watermark
```

## 填写要点

- 前中背景三层**各写具体元素**，这是纵深感的来源；只写「很有层次」没用。
- 大气透视 `atmospheric perspective` + 远处 `haze` 是概念图质感的快捷键。
- 24mm 广角 + 低机位 = 宏大；高空俯瞰则写 `aerial view, high angle`。
- 氛围词决定用光方向：神秘 = 逆光+雾；宏大 = 低角度侧逆光+长影。
